Guía Rápida de Personalización

1. Cambiar Nombres y Fecha

Abre index.html y busca los nombres:

<!-- Cambiar estos nombres -->
<span class="name">María</span>
<span class="name">Carlos</span>

Para la fecha, edita script.js:

// Cambia la fecha de tu boda
const WEDDING_DATE = new Date('2025-03-15T16:00:00');

2. Cambiar Colores

Edita styles.css y modifica las variables:

:root {
--primary-color: #8b5a2b; /* Marrón elegante */
--secondary-color: #d4a574; /* Dorado suave */
--gold: #d4af37; /* Dorado brillante */
}
💡 Consejo: Puedes usar herramientas como Coolors o Adobe Color para elegir tu paleta.

3. Agregar Fotos

Sigue estos pasos para agregar tus fotos:

  1. Crea la carpeta de fotos
    Ya está creada: fotos/
  2. Coloca tus imágenes
    - Foto principal: fotos/novios.jpg
    - Fotos de galería: fotos/galeria/
  3. Edita index.html
    Reemplaza los placeholders por tus imágenes
  4. Comprime las imágenes
    Usa TinyPNG para optimizar
⚠️ Importante: Las imágenes deben ser cuadradas (1:1) para mejor visualización.

5. Configurar WhatsApp

Edita script.js con tu número:

// Tu número con código de país
const WHATSAPP_NUMBER = '51999888777';

6. Agregar Música

Coloca tu archivo de música en la carpeta music/:

music/
└── wedding-song.mp3

Asegúrate de que el archivo se llame exactamente wedding-song.mp3

7. Probar la Invitación

Abre el archivo index.html en tu navegador móvil:

Ver Invitación Vista Previa Configuración

8. Compartir tu Invitación

Una vez personalizada, puedes compartirla por:

WhatsApp
Facebook
Instagram
💡 Consejo: Sube los archivos a Netlify o GitHub Pages para obtener un enlace permanente.
